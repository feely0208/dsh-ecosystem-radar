# @deepwhale-cn/dsh-ecosystem-radar

把本机「生态雷达」的数据做成**插件面板** —— 打开侧栏就能看到：DSH 插件生态最近在长什么、哪些行业格子是空的、今天有什么变化。

**关键词**：插件生态 · 供给密度 · 空白位 · 竞品观察 · 生态雷达 · DeepSeek Harness 插件

## 为什么要有面板

雷达脚本每天在后台跑、产出 `snapshot.json` 和 `每日增量-YYYY-MM-DD.md`，但**没人会天天去翻文件**。
面板解决的就是这一步：把「新增了什么 / 哪里没人做 / 今天变了什么」直接摆在你面前。

## 面板里有什么

| 页签 | 内容 |
|---|---|
| 概览 | 插件总数、近 7 天新增、Star 总量、最新报告日期、采样时间、数据目录 |
| 新增 | 近 7 天新出现的插件（按 ★ 排序，可点开仓库） |
| 空位 | 行业 / 能力的供给密度条：越靠前越空，**≤1 基本没人做**；⚠️ 供给 0 ≠ 有机会 |
| 报告 | 最新一份「每日增量」原文 |

右上角「刷新快照」会在本机跑一次 `radar.sh snapshot`（走 GitHub API，通常几十秒；受限流影响可能失败并如实报错）。

## 安装

```bash
dsh plugin --profile web add @deepwhale-cn/dsh-ecosystem-radar
```

装好后侧栏会多一个「生态雷达」图标。

## 前置

- 需要本机已有雷达脚本与数据：`~/.dsh/skills/dsh-ecosystem-radar/radar.sh`、
  `~/深鲸运营/生态雷达/snapshot.json`。
- 数据目录可用环境变量 `DSH_ECOSYSTEM_RADAR_DIR` 覆盖（默认 `~/深鲸运营/生态雷达`）。

## 边界（重要）

- **只读展示**：面板不改快照、不改报告；「刷新」只是让脚本重抓一次。
- **供给 ≠ 需求**：空位榜只测「有多少人在做」，是否值得做要回到三项判据核实。
- **限流**：GitHub 搜索有速率限制，刷太勤会失败，失败会如实显示原因，不伪造数据。
